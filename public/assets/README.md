Character models and textures go here.

    npm run add-model -- <file.glb>

See ../../docs/ASSETS.md for the full pipeline, including how to get a
riggable, animatable character out of Meshy.

Files in this folder are ignored by git except this README — models are large
and binary, and belong in a release rather than in history. Remove the ignore
rule in .gitignore if you want to commit one.
